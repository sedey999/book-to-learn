# 卡片版式规范

> 各「学习型」引擎的版式定稿。版式属于**不可复用**的部分，各自独立成引擎；
> 共用的是转义/字体/裁白/配图等纯工具（`render_common.py`）。
> 拆卡引擎（`gen_card_tile.py`）的版式见第三节。

## 一、学习长图（`cardType: long-study` → `gen_card_long.py`）

面向**手机单列阅读**，宽 800px，高度自适应。

### 区块顺序（固定，不要调换）
```
标题区 → 金句 → 专业术语 → 核心观点 → 要点 → 来源
```
- 金句先给「情绪价值」；术语解决生词；核心观点给一句话总结；要点才是细节。
- **不放「相关链接」**：移动端保持清爽，链接只进 PDF。
- 末行一行灰字「来源 · Source: <url>」。

### 尺寸与留白
| 项 | 值 | 为什么 |
|---|---|---|
| 宽度 | 800px | 竖版单列；dpi=96 时产物宽度即 800px |
| 顶部留白 | **≥ 80px** | 避开手机刘海/灵动岛，标题不被遮 |
| 左右内边距 | 34px | |
| 底部留白 | ≥ 60px | 内容不贴底（裁白参数 `pad=64`） |
| 标题 | 35px / 800 | |
| 英文副标题 | 19px / 斜体 / 半透明 | |
| 小节标题 | 21px / 800 | |
| 正文、要点 | 22px / 行高 1.8 | 比常规正文大一档，手机上才不费眼 |
| 术语 | 21px | |
| 金句 | 24px / 600 | |
| 来源 | 15px / 灰 | |

### 配色
蓝（标题栏渐变 `#1a73e8→#1557b0`）、紫（金句）、红（术语）、绿（核心观点）、蓝（要点）。

### 生成
`weasyprint` 出 PDF，dpi=96（与 CSS 像素 1:1，所以产物宽度正好 800px），再光栅化为 PNG，
最后裁掉底部空白。**校验失败即以非 0 退出**（不要推送一个空白卡片）。

## 二、中英对照文档（`cardType: pdf-bilingual` → `gen_card_bilingual.py`）

面向**归档与精读**，A4。

### 区块顺序（固定）
```
专业术语 → 核心观点（中 + 英） → 正文翻译（逐块「中文译文 + 英文原文」）
→ 相关链接（纯文本 URL） → 来源
```

### 关键约定
- **逐块对照**：按空行切块，中英块数**必须一一对应**；推送前用
  `validate.py --payload … --zh …` 校验，块数不一致属于 error。
- **超链接纯文本**：正文里的 `[文字](url)` 只保留文字，完整 URL 统一列在「相关链接」。
- 中文正文用 16px / 行高 1.75；英文原文 13px / 斜体 / 灰色，紧跟在中文之后。
- 表格渲染为真表格（边框 `#98a1aa`、表头底色 `#eef1f4`、偶数行斑马纹）。
- 配图按资源路径映射本地文件后**真实嵌入**。

## 三、竖版知识卡片长图（`tile-*` → `gen_card_tile.py`）

面向「一图一知识点」的收藏/归档卡片。**固定比例整版**，一张卡 = 一个知识点。

### 画布比例（`ratio` / `--ratio`，`@192dpi` 时产物 = CSS 尺寸 ×2）
| ratio | CSS 尺寸 | 产物 | 场景 |
|---|---|---|---|
| `3:4`（默认） | 900×1200 | 1800×2400 | 通用竖版卡片、图文社区 |
| `9:16` | 900×1600 | 1800×3200 | 手机全屏 / 短视频封面 |
| `1:1` | 900×900 | 1800×1800 | 方形信息卡 |
| `4:3` / `16:9` | 1200×900 / 1200×675 | 2400×1800 / 2400×1350 | 横版展示 |

### 结构（固定）
```
头部（蓝色渐变 + 角标"第 X / N 张 · 卡组名" + 标题 + 副标题）
→ blocks[]（可任意个，按顺序）
→ 页脚（只有来源，不放日期）
```
左侧有一条按 `accent` 着色的竖边，作为该卡的视觉标识。

### 尺寸（k=1.0 时，随比例按 W/900 归一后再乘 k）
| 项 | 值 |
|---|---|
| 标题 / 副标题 | 50px / 22px |
| 角标 | 19px |
| 正文（text） | 26px / 行高 1.55 |
| 要点（list） | 25px / 行高 1.46 |
| 误正对比 | 25px，左侧 40px「误/正」方块 |
| 强调（emphasis） | 25px 加粗，虚线框 |
| 图示字格 | 46×46（半宽 26 / 双宽 95 / 加高 92） |
| 图示标签 | 23px，`flex: 0 0 60%` |
| 页脚 | 17px / 灰 |

### 配色语义
核心用法=蓝 `#0969da`｜要点·其他用法=橙 `#bf8700`｜易错=红 `#cf222e`（误红正绿 `#1a7f37`）｜
提示=绿｜图示=青 `#0f766e`。`accent` 决定左侧竖边与标签色。

### 自适应（关键）
**先渲染一张超长页测量内容真实高度**，超出画布则整体等比缩小字号/间距（k 从 1.0 递减，
下限 0.62），迭代至完整落入画布。因此：
- 不存在「固定高度容器溢出被静默裁剪」的问题；
- k < 0.7 说明该卡内容偏多，**应拆成两张**而不是继续缩；
- `out/_check.json` 里记录了每张卡的 k，便于批量发现「该拆」的卡。

### 校验（生成即执行，失败非 0 退出）
尺寸是否等于画布 / **PDF 是否恰好 1 页**（>1 页 = 溢出）/ 是否空白 /
**底部页脚底色带是否存在**（溢出会把页脚挤到下一页；容差 ≤3，白底与页脚底色只差 8）。

## 四、通用要求

1. 卡片顶部标「序号 / 总数」（如 `9 / 287`）= **清单绝对序号**（跳过会跳号）。
2. 章节标签显示「章节中文 · 分组」。
3. 所有文本字段经「转义 + 行内 markdown」处理，杜绝缺字（见 `pitfalls.md` 第 6、7 条）。
4. 中文破折号用 `——`；中文句内引用用中文引号。
5. 产物生成后必须校验（尺寸 + 非空白），失败中止。
